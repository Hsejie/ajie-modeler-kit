# Ajie Modeler — Being Kit

让 Being 用自然语言操控 Ajie Modeler，创建和修改三维场景、布置材质与灯光，并生成效果图。支持参数化建模、可撤销编辑和项目保存。

[在 Grove 查看与安装](https://beings.town/grove/t4XgLKIxfmHVf_07IVjnQ) · [下载 2.8.0 安装包](https://github.com/Hsejie/ajie-modeler-kit/releases/tag/v2.8.0)

## 使用要求

- Windows x64，Portal Desktop 已连接你的 Being。
- 同一台电脑上安装并打开 Ajie Modeler 2.8.0 或兼容新版。
- 包含 34 个 MCP 工具和自带 .NET 运行时的连接器；不包含建模器、渲染引擎或模型 API Key。

## 安装

在 Portal Desktop 的 Grove / Kit 列表中找到 ajie-modeler，作者为 YomiyaHina (t_VXO8mQ)，选择安装。

也可从 Releases 下载 ajie-modeler-kit-2.8.0-win-x64.tar.gz，解压后点击“导入本地 Kit”，选择包含 manifest.json 的 ajie-modeler 文件夹。不要下载 GitHub 自动生成的 Source code 包。

## 开始使用

打开建模器后告诉 Being：使用 ajie-modeler Kit，先列出打开的窗口、读取能力并确认目标项目，再开始建模。完整指南见安装包中的 BEING.md 和 MODELING.md。
